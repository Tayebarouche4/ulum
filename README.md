# فضاء العلوم الإسلامية

موقع دروس ونماذج أسئلة وتقويم مستمر. 

## الملفات
- `index.html`: واجهة الموقع (لا تحتاج تعديلا في الغالب).
- `subjects/index.json`: قائمة المواد، مثل `["islamic"]`.
- `subjects/islamic.json`: دروس وأسئلة مادة العلوم الإسلامية.

## إضافة مادة جديدة
1. انسخ `subjects/islamic.json` باسم جديد، مثل `subjects/arabic.json`، وغيّر محتواه.
2. أضف اسم الملف (دون .json) إلى `subjects/index.json`: `["islamic","arabic"]`.
3. ضع في `assessment.url` رابط صفحة النتائج الخاصة بأستاذ المادة.

لا تضع أي علامات أو أسماء تلاميذ في هذا المستودع، فهو عام.
