# فضاء العلوم الإسلامية

## بنية الملفات
- `index.html`: واجهة الموقع.
- `subjects/index.json`: قائمة المواد، مثل `["islamic"]`.
- `subjects/islamic.json`: معلومات المادة (الاسم، الأستاذ، المستويات، رابط صفحة النتائج، `maxLessons` أقصى عدد دروس لكل مستوى).
- `subjects/islamic/lessons/<المستوى>-<الرقم>.json`: **درس واحد في كل ملف**، مثل `1-04.json` (السنة الأولى، الدرس 4) و`4-05.json`.
- `assets/maps/`: صور المخططات الذهنية.

## إضافة درس
ارفع ملف الدرس وحده (وصورة مخططه إن وُجدت). يرتّبه الموقع بحسب رقمه، ويُظهر «سيُنشر قريبا» للأرقام الناقصة قبل آخر درس منشور.

## إضافة مادة
أنشئ `subjects/<مادة>.json` ومجلد `subjects/<مادة>/lessons/` ثم أضف اسم المادة إلى `subjects/index.json`.

لا تضع أي علامات أو أسماء تلاميذ في هذا المستودع، فهو عام.
